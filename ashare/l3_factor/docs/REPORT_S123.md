# 个股日内策略终审报告 — S1/S2/S3 半年对照实验(2026-07-17)

**实验设计**:控制变量三方案 vs 基准 v1a,同口径(每5分钟触发/每边3只/5万每腿/持8分钟/底仓T+0/vloop闭环),
126 个交易日(2026H1)× 真实排队成交(vsim),零失败。策略参数以 2026-06 周样本设计 → 本回测对其部分样本内,
负结论直接采信(选择级泄漏协议)。

## 结果与归因

| 方案 | 配置 | 净bp/双边 | Δ vs 基准 | 累计净 | 盈利天 |
|---|---|---|---|---|---|
| v1a 基准 | eat_age 单因子·提档进·穿价出 | −11.04 | — | −290.5 万 | 0/126 |
| S1 信号包 | 三快枪合成(kept_rem+chain−eat_age) | −10.60 | **+0.44** | −286.9 万 | 0/126 |
| S2 执行包 | 高价池(≥15元)+ 两段式出场 | −8.68 | **+2.36** | −209.0 万 | 0/126 |
| S3 全家桶 | 信号包+执行包 | **−8.36** | **+2.69** | −211.0 万 | 0/126 |

可加性成立(0.44+2.36=2.80 ≈ 2.69):信号与执行两包近乎独立,无交互增益。

## 两个关键教训

**① 信号包几乎无效(+0.44bp)——期限错配吃掉了一切。** kept_rem_imb 的即时 IC 高达 0.088(全项目最强),
但它一分钟内衰减完;而策略结构是"提档进场(成交需几十秒~几分钟)+ 持有8分钟"——等仓位建立,超短 alpha
已死,组合分的增量选股力在 8 分钟尺度上与单因子几乎无差。**信号强度必须在"持有期"这把尺子上度量,
h=1min 的王牌塞进 hold=8min 的策略等于没换。** 超短信号唯一的正确容器是事件级执行(择时进场那一分钟),
不是选股。

**② 执行包稳定值 +2.36bp,与冒烟测一致。** 高价股池压 tick 地板 + 两段式出场省半价差,两项工程改进
可复制、可叠加——它们同样适用于将来任何 A 股股票执行场景(执行择时 overlay 的工艺基础)。

## 终审判决

全部已知最优配置(S3)= **−8.36bp/双边,126 天零盈利日**。个股分钟级方向策略在
「alpha 天花板 8~11bp(不随持有期增长) < 成本地板 ~20bp(费税9 + 残余穿价/逆选)」的结构下无解。
**本方向正式关档**;此表为终审依据,后续如有人重提,以此为基线要求其先解释成本堆栈如何翻转。
